# AR Clock

カメラに映る景色をWebGLでマンガ調・グリッチ調に加工し、1〜5秒は毎秒1枚ずつ時刻カード、6〜0秒は映像、を10秒ごとに繰り返す時計です。

- 映像：外側カメラ（既定）／内側カメラ／手元の写真・動画／サンプル映像
- 見た目：ベース（カラー／モノクロ、濃淡調整）× フィルタ（なし／フィルム調／ビビッド／マンガ／ポップアート／ミニチュア／魚眼）× グリッチの組み合わせ
- 音：Web Audioでその場で生成するBGM（音色10種：ピアノ、エレクトロ、オルゴール、鳥のさえずり、8bit、ローファイ、口笛、ジャズ、田舎のさえずり、森のさえずり。時間帯で変化）と時報
- 言語：英語（既定）／日本語
- 場所の表示：オンにすると現在地の許可を求め、都道府県を調べるために座標を国土地理院の逆ジオコーダ（mreversegeocoder.gsi.go.jp）へ送ります。日本国内のみ対応

## 使い方

`index.html` ひとつで動きます。カメラはHTTPS（または localhost）でしか使えないので、GitHub Pagesなどで配信してください。

ローカルで試す場合：

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```
