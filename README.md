# AR Clock

カメラに映る景色をWebGLでマンガ調・グリッチ調に加工し、1〜5秒は毎秒1枚ずつ時刻カード、6〜0秒は映像、を10秒ごとに繰り返す時計です。

- 映像：外側カメラ（既定）／内側カメラ／手元の写真・動画／サンプル映像（sample.mp4、渋谷のスクランブル交差点）
- 見た目：ベース（カラー／モノクロ、濃淡調整）× フィルタ（なし／フィルム調／ビビッド／マンガ／ポップアート／ミニチュア／魚眼）× グリッチ（強さ調整可）の組み合わせ
- 音：Web Audioでその場で生成するBGM（音色8種：ピアノ、エレクトロ、オルゴール、鳥のさえずり、8bit、ローファイ、口笛、森のさえずり。時間帯で変化）と時報
- 言語：英語（既定）／日本語
- 場所の表示：オンにするとアプリ内で確認してから現在地を使います（答えと日時を端末に記録し、許可済みなら次回は聞きません）。日本国内は都道府県（ローマ字）を出すために座標を国土地理院の逆ジオコーダ（mreversegeocoder.gsi.go.jp）へ、海外は国名を出すために約1km単位に丸めた座標を BigDataCloud（api.bigdatacloud.net）へ送ります

- バックグラウンドに回るとカメラと音を止め、戻ったときに「カメラ→BGM」の順に確認してから再開します

## 使い方

`index.html` とサンプル映像の `sample.mp4` で動きます。カメラはHTTPS（または localhost）でしか使えないので、GitHub Pagesなどで配信してください。

ローカルで試す場合：

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```
