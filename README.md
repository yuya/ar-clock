# AR CLOCK

カメラ越しの景色に、時計を重ねる。

カメラに映る景色をWebGLでフィルタ・エフェクト加工し、10秒ごとに、1〜6秒は毎秒1枚ずつ時刻カード、7〜0秒は映像、を繰り返す時計です。

- 映像：外側カメラ（既定）／内側カメラ／手元の写真・動画／サンプル映像（sample.mp4、渋谷のスクランブル交差点）
- 見た目：ベース（カラー／モノクロ、濃淡調整）× フィルタ（なし／フィルム調／ビビッド／マンガ／ポップアート／ミニチュア／魚眼）× エフェクト（グリッチ／周辺減光／古いフィルムのゴミとキズ／ビートパンチ、どれも強さ調整可）の組み合わせ。調整スライダーは、対応する項目を選んでいるときだけ表示
- 音：Web Audioでその場で生成するBGM（音色9種：ピアノ、マリンバ、エレクトロ、オルゴール、8bit、ローファイ、口笛、鳥のさえずり、虫の声。時間帯で変化）と時報
- 初期状態：カラー／フィルタなし／グリッチのみON（すでに設定を保存している人はその設定のまま）
- フィルタに「白黒2色」「携帯ゲーム機（4階調の緑）」を追加。あみ点で明暗を表す
- 長押しクリップ（Webのみ・iOSアプリでは無効）：画面を長押しすると（0.35秒〜最大6秒）カメラの映像を、フィルタ前のまま録画。ビデオや写真を流していたら、やめてカメラに切り替えてから録る。録画中はパネル（抜き文字）が止まる。離すとクリップが往復ループ再生される。解除：パネルや抜き文字の最中でなければシングルタップ、いつでもダブルタップ（解除すると通知）。再生中に長押しすると、元のビデオ（フィルタ等なし）の保存確認が出る
- 白黒2色／携帯ゲーム機に「ピクセル化」（横160ドット、初期はOFF）
- フィルタに サーマル／CRT／エッジ／点群(LiDAR) を追加（白黒2色・携帯ゲーム機ベースでは選べない）。データモッシュは見送り
- 設定はタブ式（映像／ベース／フィルタ／エフェクト／表示／音）。ベースとフィルタは、いま映っている1コマに各効果をかけたサムネイル付き（端末内で生成、通信なし）
- タップ：一時停止とダブルタップのグリッチは廃止
- 抜き文字：黒の回は、時間帯の色（パネルと同じ）が背景になる。白の回はこれまでどおり
- ベース：カラー／モノクロ／白黒2色／携帯ゲーム機（4階調の緑）。後ろ2つはあみ点の強さをスライダーで調整でき、選んでいる間はフィルム調・ビビッド・マンガ・ポップアートは使えない
- カメラ切替：カメラを映しているとき、左下のボタンで前面・背面を切り替え
- 言語：初回は端末の優先言語で自動判定（日本語なら日本語、それ以外は英語）。設定で切り替えると、その選択を覚えます
- 場所の表示：オンにするとアプリ内で確認してから現在地を使います（答えと日時を端末に記録し、許可済みなら次回は聞きません）。日本国内は都道府県（ローマ字）を出すために座標を国土地理院の逆ジオコーダ（mreversegeocoder.gsi.go.jp）へ、海外は国名を出すために約1km単位に丸めた座標を BigDataCloud（api.bigdatacloud.net）へ送ります

- 時計の表示は「パネル」（白と、時間帯ごとの1色）と「抜き文字」（大きな数字の中だけ映像が動く）から選べます
- 選んだ動画は往復再生（最後まで行ったら逆向きに頭まで戻り、また通常再生。戻せない端末では普通のループ）。サンプル映像は、行って戻る形に作ってある動画をループ。時刻カードが出ている間は映像を止め、カードが開くと同時に再開
- 時刻カードは毎10秒の1〜6秒、7秒で映像へ戻る。「流さない」を選ぶと時報も鳴らない
- バックグラウンドに回るとカメラと音を止め（音は短くフェードアウト。OSが先に音を切った場合は効きません）、戻ったときに「カメラ→BGM」の順に確認してから再開します

## 使い方

`index.html` とサンプル映像の `sample.mp4` で動きます。カメラはHTTPS（または localhost）でしか使えないので、GitHub Pagesなどで配信してください。

ローカルで試す場合：

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

- 設定シート: タブはピル型バー（選択中は白の強い角丸）、フィルタ等のサムネは4:3の横長で上下クリップ。
- 抜き文字は黒に戻しました（時間帯の色づけは廃止）。
- フォント: 本文は Inter → IBM Plex Sans JP、サイト名・場所/日付は Urbanist 優先。時計のフォントは「表示」タブのプルダウンで Archivo / Urbanist を選べます（Web のみ。iOSアプリの設定画面にはまだありません）。
