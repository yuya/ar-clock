# AR Clock

カメラに映る景色をWebGLでマンガ調・グリッチ調に加工し、毎分0・10・20…秒に時刻カードが入り、6秒で映像に戻る時計です。

- 映像：外側カメラ（既定）／内側カメラ／手元の写真・動画／サンプル映像
- 見た目：ベース（カラー／モノクロ）× フィルタ（なし／フィルム調／ビビッド／マンガ／ポップアート）× グリッチの組み合わせ。線の太さは調整可
- 音：Web Audioでその場で生成するBGM（音色6種：ピアノ、エレクトロ、オルゴール、ローファイ、8bit、鳥のさえずり。時間帯で変化）と10秒報（6〜9秒に短い音、0秒に長い音）

## 使い方

`index.html` ひとつで動きます。カメラはHTTPS（または localhost）でしか使えないので、GitHub Pagesなどで配信してください。

ローカルで試す場合：

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```
