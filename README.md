# AR Clock

カメラに映る景色をWebGLでマンガ調・グリッチ調に加工し、10秒ごとに時刻カードへ切り替わる時計です。

- 映像：外側カメラ（既定）／内側カメラ／手元の写真・動画／サンプル映像
- フィルタ：マンガ、マンガ＋グリッチ、グリッチ、モノクロ、ポップアート、フィルム調、フィルタなし
- 音：Web Audioでその場で生成するBGM（音色4種、時間帯で変化）と時報

## 使い方

`index.html` ひとつで動きます。カメラはHTTPS（または localhost）でしか使えないので、GitHub Pagesなどで配信してください。

ローカルで試す場合：

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```
